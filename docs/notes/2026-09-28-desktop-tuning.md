  the `time` uniform) was ruled out: animated shaders make picom repaint at
  the refresh rate (60 fps instead of 15) and need the glx/egl backend, which

- Already lean: bar.sh updates every 5 s and only on change; st cursor

- fetch --pinned: paused headers polled at 50 Hz (usleep 20 ms); now pselect

  best matches (ink target = lum^0.7 * densest ink; GXWC_INK_CURVE at build).
  Cost: CPU unchanged (~0.15-0.35% of a core), gxwc GPU ~0.45% -> ~0.8%,
  bench 0.50 -> 1.18 ms/frame full-screen; compositing unchanged (same area).
  Frame-to-frame change is lower than density picking (10.7k vs 12.2k px).
  Captures: ~/Pictures/gxwc-captures. RSS: planet maps freed after upload.
- 2026-09-29 (later still): planets at half size (all params size /2; window
  984 -> 495 px, so ~1/4 of the compositing area), 3x5 cells (the 4x6 glyphs
  packed without their gap), matching on 3x3-blurred pixels + 30x mean-ink
  term (plain per-pixel L2 vs binary glyphs just thresholds at 50%), ink
  target lum^0.7*0.5, cells with mean lum < 0.08 blank, atmosphere rim
  pow(1-n.z, 5) (was 2.5: it laid faint glyphs over dark oceans), Earth
  `black = 0.12` (map-luma cutoff: oceans empty). gxwc-wallpaper now passes
  --planet for earth too. Live: CPU ~0.35%, gxwc GPU ~1.3%.
  Up close 3x5 reads as dither-like texture; 4x6 kept letters legible.
- 2026-09-29 final (for now): planet sizes restored (the user wanted smaller
  chars, not smaller planets). 3x5 packed cells looked like dithering (glyphs
  touch); 4x6 cells (3x5 glyph + the font's gap) with the classic ASCII-art
  alphabet (build.rs GLYPHS: . , : ; ' ` - _ = + * ! / \ | ( ) < > [ ] ^ ~ i l 1
  I T 7 L J 0 O Q # @) is the smallest that reads as ASCII. Matching: 6 samples
  per cell interpolated to 15 px, 3x3 blur + 30x mean-ink term, binary search
  to glyphs within 0.12 ink (identical output, ~45% cheaper). Dark floor 0.08,
  Earth black = 0.12. Build knobs: GXWC_CELL, GXWC_GLYPHS, GXWC_INK_MAX (0.5),
  GXWC_INK_CURVE (0.7), GXWC_DARK (0.08). Bench 1.02 ms/frame full screen.
